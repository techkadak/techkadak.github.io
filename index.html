Q&A

Sawaal jawab

Ye apps sach mein free hain?

Har app ke saath badge hai: FREE ya FREEMIUM (basic free, kuch features paid). Limit wali line bhi likhi hai. Free/paid status company badal sakti hai — install se pehle official page dekh lo.

Download link safe hain?

Hum sirf official links dete hain: Play Store, F-Droid, GitHub ya app ki apni website. Koi modded / cracked APK nahi.

Roz naya app kaun daalta hai?

Har din subah 9 baje 5 naye verified apps apne aap add hote hain (sabse naye upar) — ek curated list se, ya AI mode on ho to F-Droid / GitHub ke official data se. AI wale apps pe "AI-added" tag hota hai.

F-Droid kya hai?

F-Droid open-source Android apps ka official store hai. Wahan ke apps free hote hain aur unka source code public hota hai.

Is site ko app ki tarah kaise rakhein?

Android (Chrome): menu ⋮ → "Install app" / "Add to Home screen". iPhone (Safari): Share button → "Add to Home Screen". Icon home screen pe aa jayega aur site full screen khulegi.
